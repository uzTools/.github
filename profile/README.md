Free, open-source software for classic Macintosh computers, from the 1986 Mac Plus to Mac OS 9.

Small tools that run on the Mac itself: no extensions, no installers, light enough for a floppy and the oldest hardware.

- **[MacExtract](https://github.com/uzTools/MacExtract)**: opens StuffIt, Compact Pro, BinHex, DiskDoubler and many other vintage archives on the Mac they were made for.
